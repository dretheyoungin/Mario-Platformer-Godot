# 🎮 My First 2D Mario Platformer Engine

A custom-built 2D side-scrolling platformer baseline loop engineered using the **Godot 4 Engine**.

## ✨ Current Features Fully Implemented:
* **Smooth Physics & Vector Mechanics:** Precise running acceleration, natural deceleration, and jumping arithmetic.
* **Smart Camera2D Tracking:** Viewport smoothly slides and lags behind the character to keep focus centered.
* **4-Way Character Controls:** Character successfully runs, jumps, turns his body layout, looks up, and crouches using the keyboard arrows.
* **Infinite Sidewalk Runway:** Extended level ground layout map to safely test speed variables.
* **Visible Floating Platforms:** Custom-placed jumping block obstacle stairs styled cleanly for navigation testing.
* **Deadly Fall Pit Sensor:** Area2D trigger line under the map that detects boundary drops and reloads the map scene automatically.
* **Winning Goal Flag:** Functional finish line boundary box that freezes the player in place and prints a victory signal upon contact.

## 🛠️ Engine Version
* Built with **Godot 4.x** (Compatibility Renderer Mode).
